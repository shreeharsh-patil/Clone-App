# Clone Apps v0.5.2

- Clone an installed app through **Add App → select the app → Install separate copy**. After Android’s one-time work-profile setup, choose **Install in work profile**, then **Open work copy**.
- The work copy runs with its own Android app storage and starts with fresh data. Android installs the existing base and split APKs using its package installer. An app’s sign-in, licensing, and eligibility are still determined by the app and Android.
- Open saved copies from **Settings → Work profile copies**. Use **Private Space and phone options** if your phone blocks a new work profile or you want a separate Play Store on Android 15 or newer.
- The first-party probe and its per-instance Bluetooth controls remain available.
